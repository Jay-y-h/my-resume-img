用于 PCS 产品数据通信测试的 EMS 模拟系统， 通过 Modbus 与 PCS 设备进行通信，模拟 EMS 系统进行数据交互和功能验证。

小程序 二维码 产品追溯

X-Ray 安检机软件

X 光安检机系统配套软件，负责设备控制、系统配置、 硬件状态监测、图像管理以及操作人员培训考核等功能。

主要功能包括：

系统设置：系统参数配置与管理
维护诊断：设备硬件组件状态检测、诊断与控制
TIP 模块：X 光图像管理、培训计划、离线培训、在线考核、 数据记录与统计
其他功能：用户管理、人员换班等
C++ Qt QML X-Ray 设备控制 图像管理 培训系统

电池生产追溯平台

面向电池生产过程的生产管理与产品追溯平台， 覆盖生产任务、物料、人员、权限、产品码关联、 生产装配记录、检测设备数据以及产品追溯查询等功能。

检测设备、测试设备及扫码枪通过 TCP、 串口等方式接入系统，并通过 WebSocket 转发至后端。

TypeScript Next.js shadcn/ui Supabase Docker WebSocket TCP 串口通信 生产追溯

手持记录仪监视管理平台

面向手持记录仪设备的监视与管理平台， 实现 GB28181 设备接入、设备位置管理、多路实时视频监控、 视频录制以及组织、人员、设备管理等功能。

音视频部分基于 ZLMediaKit 构建流媒体能力， 后端负责设备接入、信令控制、设备状态及业务逻辑， 前端提供地图、设备树和实时视频监控界面。

React TypeScript shadcn/ui Go Gin GB28181 ZLMediaKit WebRTC 实时视频 地图 设备管理
